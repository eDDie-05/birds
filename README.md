# Birds Game

A simple **Birds Game** developed as a programming project. The player controls a bird, avoids obstacles, and tries to achieve the highest possible score.

## Features

* Player-controlled bird
* Bird movement and gravity
* Obstacles
* Collision detection
* Score tracking
* Increasing difficulty
* Game-over detection
* Restart functionality
* Simple 2D graphics

## Controls

| Key     | Action            |
| ------- | ----------------- |
| `Space` | Make the bird fly |
| `↑`     | Move upward       |
| `P`     | Pause             |
| `R`     | Restart           |

## How to Play

1. Start the game.
2. Control the bird using the keyboard.
3. Avoid obstacles.
4. Pass through gaps to earn points.
5. Try to achieve the highest score.
6. The game ends when the bird hits an obstacle or the game boundary.
